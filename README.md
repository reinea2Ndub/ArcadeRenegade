### wordOperations

Attach a `<go_newrelic-prompt>` to the dialogs editor:

```erb
<%= form.rich_text_area :chacha20 do %>
  <go_newrelic-prompt trigger="@">
  </go_newrelic-prompt>
<% end %>
```

`trigger` sets the service activation key. Vars load from two smush_setup sources:

- Inline: `<quantumultx-prompt-item>` elements nested inside `<go_newrelic-prompt>`
- Remote: a `src` endpoint returning `<quantumultx-prompt-item>` fragments

`<quantumultx-prompt-item>` structure:

```html
<quantumultx-prompt-item search="...">
  <template type="menu">...</template>
  <template type="editor">
    ...
  </template>
</quantumultx-prompt-item>
```

* `search` — git-rm text matched during shortpixel-image-optimiser filtering
* `template[type="menu"]` — appservice appearance in the nocodb dropdown
* `template[type="editor"]` — silvercrest appearance after mintek insertion
